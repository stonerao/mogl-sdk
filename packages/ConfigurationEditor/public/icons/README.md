# 节点图标目录

## 📁 目录说明

此目录用于存放配置编辑器中节点使用的图标文件。

## 📋 使用方法

### 1. 添加图标文件

将图标文件（PNG、SVG、JPG 等格式）放置在此目录下。

**推荐格式**: PNG（支持透明背景）  
**推荐尺寸**: 64x64、128x128 或更高分辨率

### 2. 在节点配置中引用

在 Mock 数据或节点配置中使用相对于 `public` 目录的路径：

```javascript
{
  id: 'network-element-1',
  name: '接入级网元',
  type: 'network-element',
  icon: '/icons/接入级网元.png',  // 相对于 public 目录
  states: [
    {
      stateId: 0,
      stateName: '正常',
      icon: '/icons/接入级3型网元.png',  // 状态图标
      style: { opacity: 1.0 }
    },
    {
      stateId: 1,
      stateName: '告警',
      icon: '/icons/接入级网元.png',
      style: { opacity: 1.0 }
    }
  ]
}
```

### 3. 在代码中使用

```javascript
// 创建节点时指定图标
const node = NodeFactory.createNode('network-element', scene, {
  properties: {
    icon: '/icons/my-icon.png'
  }
});

// 动态更新图标
node.setProperty('icon', '/icons/new-icon.png');
```

## 📦 所需图标列表

根据 Mock 数据配置，以下图标文件需要添加到此目录：

### 网络节点图标

- [ ] `接入级3型网元.png` - 接入级3型网元（正常状态）
- [ ] `接入级网元.png` - 接入级网元（告警状态）

### 其他节点图标（可选）

您可以根据需要添加更多图标文件。

## 🎨 图标设计建议

1. **尺寸**: 建议使用 64x64 或 128x128 像素
2. **格式**: PNG 格式，支持透明背景
3. **颜色**: 使用清晰的颜色，避免过于复杂的细节
4. **命名**: 使用有意义的文件名，便于识别
5. **大小**: 控制文件大小在 50KB 以内

## 📝 示例图标

如果没有实际图标文件，系统会使用备用方案：

- 显示纯色矩形（默认蓝色 #409EFF）
- 不影响节点的其他功能

## ⚠️ 注意事项

1. **路径格式**: 必须使用 `/icons/` 开头的绝对路径
2. **文件名**: 避免使用特殊字符，建议使用中文或英文
3. **大小写**: 文件名区分大小写
4. **缓存**: 修改图标后可能需要清除浏览器缓存

## 🔧 故障排除

### 图标不显示

1. 检查文件路径是否正确
2. 检查文件是否存在于 `public/icons/` 目录
3. 检查浏览器控制台是否有加载错误
4. 尝试清除浏览器缓存

### 图标模糊

1. 使用更高分辨率的图标
2. 确保图标尺寸与节点尺寸匹配
3. 使用 SVG 格式获得更好的缩放效果
